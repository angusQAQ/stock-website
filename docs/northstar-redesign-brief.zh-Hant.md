## 使用者指定的方向

高度仿照 [Longbridge 香港英文網站](https://longbridge.com/hk/en?channel=OWNN00060) 的字詞、顏色與排版。先分析實際頁面，再制定 Northstar 的藝術風格並實作。保留「證券公司網站、資訊密集、以圖表和數字為主」及「報告先看結論、理由、風險」兩項既有要求。

這次改版的對象是既有美股研究平台。參考網站的導覽、品牌表現與資訊層級應轉譯成行情及研究操作，不直接將開戶、優惠或下載程式等券商行銷流程放進 Northstar。

## 改版前 Northstar 的現況

以下來自本專案程式，並非參考網站的分析：

- 深色背景 `#0c1018`、面板 `#101620`、邊框 `#222c3c`，主按鈕為藍色。圖表也使用固定深色值，改換視覺時必須同步處理。
- 桌面有固定 228px 側欄、中央行情及分析區、右側資產摘要。既有導覽包括市場工作台、我的資產、分析紀錄、連線與資料狀態。
- 基礎字級 13px；手機樣式部分文字降至 8–10px。新規範需優先保障正文、數據標籤與按鈕可讀性，以重排處理密度。
- 行情包含市場摘要、個股報價、盤前／盤後時段、K 線、成交量、MA20／50 及 RSI。空資料與錯誤狀態也是需要設計的正式狀態。
- 分析依賴明確選擇期間和風險，並由使用者按下按鈕。視覺調整不能將此流程改成自動執行。
- 目前正式前端尚未接上 API。新設計須保留真實的不可用狀態，不能為填滿畫面加入看似真實的報價、資產或報告。

## 實作範圍與驗收

1. 先完成參考證據與分析，將確認的視覺方向寫入介面簡報；實作完成後記錄 `DESIGN.md` 與可重用 tokens。
2. 統一品牌區、導覽、股票搜尋、市場摘要、報價、圖表、持倉、報告、表單與所有空／錯誤狀態。
3. 報告維持結論 → 理由 → 風險 → 配置與參考價位 → 可展開證據的順序。保留數據時間與分析期間。
4. 驗證桌面、平板及手機，包含 1440px、768px、390px、320px；資料表可以有明確的局部橫向捲動，整頁不得溢出。
5. 驗證鍵盤搜尋與選股、導覽、圖表期間、風險設定、報告展開、對話框，以及未接通 API 時的操作限制。
6. 介面修改後執行 `npm test`、`npm run build`，查看實際瀏覽器截圖，完成 Impeccable 的適用檢查與獨立完成審查。
7. 每次邏輯更新提交 Git；沿用既有 GitHub Pages 網址。推送成功不等於已驗證線上部署，部署狀態分開報告。

## 本次已落實的視覺與排版

- 採用白色表面、淺灰背景、近黑色標題與數字；主操作使用橙色 `#ff5b00` 配深色文字，較小的橙色連結使用深橙 `#b63d00` 維持對比。
- 將固定深色側欄改為橫向頂部導覽，整合品牌、股票搜尋與記錄資金入口；四個主要頁面沿用同一套元件。
- 以較大的中文標題與簡短說明建立閱讀層級。桌面工作區保留股票清單、報價／圖表／分析及美元資產三個區域；平板與手機按工作順序重排，股票清單改為局部橫向捲動。
- K 線、成交量、均線、十字線與文字讀取共用 CSS 色彩變數，避免圖表殘留舊的深色背景。
- 報告保留結論、理由、風險、參考價位、倉位計算與可展開的完整證據；資產表格維持數字對齊與局部橫向捲動。
- 搜尋支援方向鍵、Enter 選股及 Escape 關閉；主要導覽、股票及期間選取提供可辨識的選取狀態。切換頁面重設捲動位置，窄螢幕標題以完整詞組換行。
- 保留沒有 API、沒有行情、沒有持倉及沒有報告的真實狀態。驗證時用到的行情與報告只存在於本機瀏覽器攔截器，不包含於正式程式或部署資產。
