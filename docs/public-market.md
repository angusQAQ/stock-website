# GitHub Pages 公開行情連接

0.3.1 解決沒有後端時只顯示圖表佔位區的問題：直接在訪客瀏覽器載入 TradingView 官方免費圖表及 ETF 報價帶，毋須 Cloudflare、Mac 或 API 金鑰。原有網址不變。

## 使用

- 點選股票清單或搜尋大型美股／ETF，公開圖表隨股票更新。BRK-B 對應 `NYSE:BRK.B`，各支股票明確指定交易所。
- 0.4 明確指定 `interval`，日K／5日K／週K／月K代表每根的週期；已移除會讓來源自動選分時的 `range` 參數。這不是只看最近一天／五天／一個月；圖內可縮放、拖曳、查看成交量並選擇技術指標。來源的交易時段、盤前／盤後、延遲標示與可用歷史範圍為準。
- 沒有研究 API 時，預設「TradingView 公開行情」。API 已接通時可選 Yahoo 圖表；來源失敗會轉用公開圖表。一般時鐘更新不會重新建立嵌入圖表。
- 官方程式載入失敗或逾時時，顯示重試及官方來源連結。嵌入框架出現不會被判為已取得實時價格，也不顯示虛假的已連線綠燈。
- 圖內報價不會被擷取或當成分析輸入。已移除網站資產功能。Codex 自動報告仍需要研究 API／Mac；未連接時按分析會開啟手動複製題目，明示結果不會自動回寫。四種價位線只畫在自有研究報告圖，公開嵌入圖無法注入自訂線。

同時依兩則瀏覽器標註，移除「美股研究，心中有數。」及其說明，以及分析區底部「從數據出發，形成自己的判斷」整個介紹區。市場頁保留螢幕閱讀器可讀的頁名及緊湊的來源／紐約時間列。

## 實際搜尋的開源參考

GitHub 搜尋找到 [react-ts-tradingview-widgets](https://github.com/JorrinKievit/react-ts-tradingview-widgets)，已讀取 README、MIT 授權及 AdvancedRealTimeChart／Widget／TickerTape 原始碼；核對的 main commit 為 `04a3eddfc4e4278a9a904865f20ebb8673f722e7`。本專案保留自己的 React 元件，按其公開介面使用官方程式，沒有新增該套件依賴。

實際載入：

- `https://s3.tradingview.com/tv.js`
- `https://s3.tradingview.com/external-embedding/embed-widget-ticker-tape.js`

開源的是整合參考及原有 Lightweight Charts；TradingView 行情／嵌入服務依其條款提供，不能稱為開源市場數據或交易所全量即時授權。保留官方品牌與來源連結，不重包裝、提取或把來源資料轉售。

## 驗證範圍

新增測試覆蓋交易所／特殊代碼、全部期間、官方程式共用載入、失敗重試及逾時。瀏覽器另外檢查 1440／1466／790／390／320px、股票與期間切換、時鐘更新不重建、錯誤恢復、兩段刪除文案不再出現，以及沒有後端 API 請求或模型呼叫。

本機嵌入契約測試只標示測試框架，沒有合成報價或 K 線。此雲端對 TradingView 官方程式的實際請求被目的地主機政策拒絕（CONNECT 403），所以不能把本機測試說成已驗證真實行情。正式網站須以訪客瀏覽器的實際載入結果驗收；圖表來源的交易所權限與延遲也需按其標示判讀。

0.4 的期間契約與真實日K聚合已有本機測試；使用者截圖顯示原有公開嵌入圖能在其瀏覽器載入。本雲端仍不能獨立核對來源即時性或更新後週期的實際供應商畫面；不得把契約測試當成供應商驗證。


## 0.4.1 清單現價

依新瀏覽器標註刪除頂部 AI 服務提示列；分析功能的狀態仍在分析操作內呈現。公開模式的股票清單不再顯示「看走勢／圖內查看價格」，改為每檔的官方 Single Ticker 報價元件，載入 `https://s3.tradingview.com/external-embedding/embed-widget-single-quote.js`。現價及升跌幅在來源框架內隨來源更新，不依賴 Northstar API、不需金鑰。休市或延遲資料不保證每秒改價，沒有隨機數或假跳價。

股票名稱按鈕繼續選擇 Northstar 主圖；官方報價及來源連結保留。元件寬度為 100%，側欄及手機橫向清單預留完整報價空間；不擷取框架資料、不裁去署名或延遲標示，也不把價格用於模型輸入。來源出錯可逐檔重試及開啟官方圖表。切換所選股票、時鐘及研究期間不重新掛載其他股票報價；切換熱門／ETF 清單才替換其成員。已接通且使用 Yahoo 模式時，原有價格每五秒檢查更新的邏輯保留。

整合另核對開源參考同一固定 commit `04a3eddfc4e4278a9a904865f20ebb8673f722e7` 的 SingleTicker 與 Ticker 設定。公開服務自身不是開源市場數據。雲端對 TradingView 的實際網路驗證仍受限制，需與本機有明示標籤的元件契約測試分開判讀。

後續同輪標註再移除整個「股價為甚麼會變？」通用教學區塊，分析標題改為「股票分析」。報告內的白話、新聞因果與來源不受影響。
