# 已確認的網站需求

本文件記錄需求訪談的結果。網站第一版原始碼與本機執行已完成；正式部署、實際行情連接與 Mac 訂閱分析仍待驗證，詳見 `deployment.md`。

## 使用方式

個人使用的美股研究網站，以大型美股及一般 ETF 為主。支援找股票、個股分析及持倉檢視。使用者先選擇短線、波段或長期，再按「分析」產生詳細報告。行情更新不觸發模型分析。

介面採證券公司網站的資訊密度：報價、自選股、K 線、成交量及數據表。分析報告先顯示結論、理由、風險、參考價位和配置建議，詳細證據可展開。以繁體中文呈現。

## 資產與交易

- 手動輸入目前可用美元現金及既有持倉的股數、平均成本。
- 後續美元入金、每筆買賣的數量、成交價及費用記入交易紀錄，自動更新現金、平均成本與損益。
- 港元不納入美股可投入現金，不推定自動換匯。
- 費用參考富途香港適用的官方收費，記錄版本與生效日期，支援實際費用修正。帳戶優惠方案尚未確認，費率尚未查核或實作。
- 保守／平衡／進取三組可調設定，結合現金、既有持倉、集中風險與止損距離計算投入金額與倉位。具體限額尚未定案。
- 不做自動交易、孖展、做空、期權、槓桿 ETF 或反向 ETF。

## 行情與模型

以 Yahoo Finance 等公開資料為優先，目標 1–5 秒刷新，包含盤前、正常時段及盤後。需顯示來源時間、時段與資料狀態；公開來源的延遲、限流與穩定性須實測，不保證逐筆即時。不合成真實財報、內部人士交易或回測績效。

使用者希望透過 macOS 上的 Codex 桌面程式及現有訂閱額度執行分析。公開網站與 Mac 之間的任務傳遞、登入支援及額度使用方式仍需驗證。不得擷取、複製或把桌面登入憑證放到網站。五個指定研究來源已列於 `config/research-sources.json`；安裝與可執行驗證另見 `research-tools.md`。

## 儲存與部署

使用者選擇雲端保存持倉，現階段不設登入或存取保護。GitHub 專案預期為 Private，但尚未查證設定。Private 倉庫不代表網站私有，也不能限制持倉 API 的讀寫；知道網址不等於身分驗證。

GitHub Pages 可用作固定前端網址，但不能提供持倉資料庫、動態行情代理或持續運作的分析服務。Pages 在私人倉庫的可用性取決於 GitHub 方案；私人網站存取另有方案條件。實際儲存與後端服務、GitHub 方案及公開資料的範圍尚未選定，不能宣稱已有永久私有網站。

每次程式或設定更新建立 Git commit，更新部署時沿用同一正式網址。個人財務資料與憑證不進入版本庫。尚未執行 push、建立公開網站或傳送個人資料。
