# 一個月研究報告與資料來源

## 使用方式

在市場研究選股票，投資期間預設為「一個月」（基準日起 30 個曆日），選風險設定，再按「分析」。行情刷新及閱讀報告不呼叫模型；原有短線、波段及長期仍可選，舊報告保持原本期間。

報告開頭列股票及五級評級：強烈買入、適度買入、持有、適度賣出、強烈賣出。資料不足時顯示「暫不評級」，不以持有掩飾缺漏。賣出評級只針對現有持倉，沒有做空或期權交易。

結論、理由與風險之後，提供白話總結、期間展望及上行／基準／下行情境、互動日 K 線、新聞影響段落，以及可展開的財報、市場、資金與價量、高管、Call／Put 證據。量化證據保存單位、期間、來源及資料日期。

報告 K 線可拖曳、縮放及移動十字線，副圖可切換 RSI／MACD，「顯示全部」還原可視範圍。展開指標可核對程式計算的 MA20／50／200、RSI14、MACD12/26/9、布林20/2、ATR14、20根支撐阻力、相對量能、CMF／OBV。樣本或成交量缺漏時顯示不可用，不把缺漏成交量當真實零成交。

## 更新與快照

市場頁的報價、所選期間 K 線、指標與美元估值每 5 秒檢查來源；背景分頁暫停，返回時立即檢查，同一輪不重疊。包括來源有提供的盤前／盤後。3M／1Y／MAX 等期間同樣持續刷新，資料刷新保留圖表實例及縮放。MAX 是來源提供的最長月線範圍，不保證涵蓋全部上市年份。

畫面分開標明報價、K 線時間與來源延遲。5 秒輪詢不是交易所即時授權，也不能令延遲數據變即時。失敗時保留既有圖表並顯示時間／錯誤，不用模擬價格補上。

完成報告保存當時的 1Y 日 K 線、指標、風險設定及預測期間。歷史閱讀不改寫證據；重新按分析才產生新研究。新聞、SEC 與期權只在 Mac 領取明確排隊的工作後擷取，與行情更新頻率不同。排隊超過 30 分鐘的快照會回報需重新分析，不呼叫模型。

## 公開資料與開源工具

2026-11-06 已實際讀取 [yfinance 官方 README](https://github.com/ranaroussi/yfinance#readme)，並檢查已固定版本的 OpenBB SEC provider 原始碼。yfinance 是開源工具，但提醒 Yahoo 資料使用權須依其條款核對；公開 API／開源軟件不代表數據能自由再發布。Northstar 擷取器使用 Python 標準庫，沒有新增付費 API 或繞過存取驗證。

| 類別 | 來源 | 接入及限制 |
| --- | --- | --- |
| 報價與歷史 OHLCV | [Yahoo Finance](https://finance.yahoo.com/) chart endpoint | Worker 已接入，含來源可提供的盤前／盤後。1Y 日線、5Y 週線、MAX 月線。未復權 OHLC；拆股須另核對，不混用復權收盤與未復權開高低。 |
| 歷史交叉核對 | [Investing.com](https://www.investing.com/) | 使用者指定參考；此雲端實測 CONNECT 403，沒有取得其數據或冒稱接入 API。分析端僅在可合法讀取時參考，不繞過登入、付費或來源限制。 |
| 財務報表 | [SEC Company Facts](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)、公司 IR | Mac 擷取 US-GAAP 數值，保留單季／全年／時點、單位、申報日與 accession；排除截止日之後披露，累計 YTD 不冒充單季。IFRS、TTM、估值及指引由模型查核原文補足，查不到列缺漏。 |
| 新聞 | Google News RSS 線索、原始發布者與公司公告 | 先收最近 30 天及發布時間；標題不算已核實全文。Codex 須搜尋並精讀原文，寫「事件→營收／成本／估值→可能反應→反證」的段落。年份隨執行日期更新，2026 年新聞不會永久當成最新。 |
| 高管交易 | SEC submissions／Form 4 XML | 最近 30 天最多五份文件，可能不完整。保留交易／申報日、P/S、授股／行權／扣稅及未知價格；10b5-1 須核對原文。未找到不代表無交易。 |
| Call／Put | Yahoo options endpoint；可核對 Cboe 公開資料 | 取最接近 30 天的一個可用到期日；覆蓋完整才加總成交量／OI 及比率。可能 401／429 或需授權，失敗保留空值。單一期權鏈不代表全市場或交易方向。 |
| 市場動態 | Federal Reserve、BLS、BEA、公司／ETF 發行商等原始披露 | 分析端須實際搜尋及引用，非預置新聞；公開資料可能有發布時滯。 |
| 資金流向 | 發行商披露、申報；CMF／OBV 僅作價量觀察 | 不從價格變化編造機構淨流入。13F 是延遲持倉，FINRA short volume 不能替代 short interest 或淨流向。 |

SEC 擷取須在 Mac 設定 `NORTHSTAR_SEC_USER_AGENT`，內容為應用名稱及真實聯絡電郵，供 SEC 存取識別。未設定就不發送 SEC 請求並列明缺漏；不用寫入 Git 或前端。請求循序、間隔至少 0.2 秒，各次有 12 秒逾時與大小限制；拒絕時不規避，不讀取本機憑證。ETF 不編造公司的營收／EPS／高管交易，改查基金披露。

## 報告品質與研究規範

實際分析指令為 `config/research-prompt.zh-Hant.md`，Worker 驗證來源為 `shared/report-schema.ts`。`npm run schema:report` 產生 CLI schema，測試檢查兩者一致。新工作要求新版結構，舊工作／歷史報告仍可讀取。

後端拒絕不存在的引用、重複／缺漏分類、未來日期的已發生事件、無日期／來源的可用證據、與評級矛盾的結論，以及把不可用證據填上數字。未有 50 根日線或個股財務量化證據時，不接受實質評級。這些是格式與一致性檢查，無法取代逐項獨立事實查核。

研究須區分事實、推論及條件情境，說明利益衝突是否已核實；不承諾回報／勝率、不冒稱持牌顧問或監管認可。免責字句不能取代資料授權、投資建議適用規則或司法管轄區的法律審查；本專案沒有宣稱取得正式合規認證。
